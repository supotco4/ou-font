# Өү — фонтод монгол Ө, Ү үсэг нэмэх

**https://ou-font.pages.dev**

Фонтоо (TTF · OTF · WOFF · WOFF2) оруулахад Ө ө Ү ү үсгийг тухайн фонтын өөрийн
хэлбэрээс автоматаар үүсгэж, шинэ фонтыг татуулна. Бүх боловсруулалт хэрэглэгчийн
хөтөч дотор (Pyodide + fontTools) явагдах тул файл хаашаа ч илгээгдэхгүй.
